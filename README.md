# Shark's Counter Attack

환경오염에 분노한 상어가 인간에게 맞선다는 콘셉트의 Unity 3D 로그라이크 슈팅 게임 프로토타입입니다.

## 프로젝트 정보

- 기간: 2024.11.30–2024.12.26
- 인원: 2명
- 역할: 공동 기획, Unity 개발
- 기술: Unity 6000.0.29f1, C#, URP, Input System, GLTFUtility

## 담당 구현

- 핵심 콘셉트 제안과 세계관·성장 구조 공동 기획
- Unity 초기 구조, 에셋·씬·카메라 환경 구성
- 이벤트 기반 반복 맵 생성·이동·삭제
- 일반 적·보스 생성과 경험치 오브젝트 연동
- 일반·강화·소환형 무기와 오디오

친구는 플레이어 이동·체력·레벨과 카드 선택 UI를 중심으로 개발했습니다. 무한 맵은 초기 구조를 제가 작성하고 공동으로 후속 수정했습니다.

## 문제 해결

맵 프리팹마다 기본 좌표가 달라 연결 위치가 어긋났습니다. 생성 기준 좌표를 통일하고, 맵 타일이 z축 기준선 이하에 도달하면 삭제 이벤트를 발생시켜 다음 타일을 생성하는 구조로 분리했습니다.

## 결과와 한계

이동→맵·적 생성→공격·처치→경험치·레벨업→보스전까지 이어지는 1개 스테이지의 핵심 플레이 루프를 구현했습니다. UI·UX, 추가 스테이지와 폴리싱은 완료하지 못해 프로토타입으로 마무리했습니다.
